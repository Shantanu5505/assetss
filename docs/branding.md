# Shantanu GitHub Brand Kit

This repository stores original visual assets for the Shantanu Dhatrak GitHub profile and projects.

## Assets
- `banners/shantanu.svg`: animated-ready profile banner artwork
- `banners/shantanu-static.svg`: static fallback
- `social/shantanu-social.svg`: 1280 × 640 social-preview artwork
- `brand/tokens.json`: shared palette and typography tokens
- `components/`: reusable README header and footer snippets
- `terminal/theme.tape`: terminal-demo palette reference

## Use in a README
```html
<p align="center">
  <img src="https://raw.githubusercontent.com/Shantanu5505/assetss/main/banners/shantanu.svg" width="100%" alt="Shantanu Dhatrak — AI and Data Science Engineer">
</p>
```

Keep published asset paths stable. Update consumers when an asset is renamed. The social preview image is separate from the README banner and must be uploaded in each repository's Settings → Social preview.

## Palette
Navy background, teal primary accent, blue secondary accent, and high-contrast off-white text. Use the same tokens for banners, README graphics, and terminal recordings.
