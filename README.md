# Shantanu Dhatrak — GitHub Brand Assets

<p align="center"><img src="banners/shantanu.svg" width="100%" alt="Shantanu Dhatrak profile banner"></p>

Original, reusable visual assets for my GitHub profile and projects. The visual system uses a deep navy base, bright teal accents, electric blue details and clean typography.

| Path | Purpose |
| --- | --- |
| [banners/shantanu.svg](banners/shantanu.svg) | Main profile banner |

## Design tokens

- Secondary accent: `#6D8CFF`
- Foreground: `#F4FAFF`
- Muted text: `#9CB5C8`

## Notes
- Keep published asset paths stable so existing READMEs do not break.
- Social preview artwork is separate from the README banner. Upload it through each repository's **Settings → Social preview**.
- All artwork in this repository was created for this profile; it is not an official GitHub asset pack.
